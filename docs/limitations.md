# Known limitations

* **Platform**: everything was tested on macOS (Apple silicon) only. Linux and Windows are untested.
* **Antigravity**: a desktop app with no command-line mode, so discovery and invocation could not be exercised automatically.
* **Dependency pins** (`requirements.lock`) record exact versions but carry no hashes.
* **Agents change**: results are for the agent versions recorded in the matrix; a different version may behave differently.
* **Agent quota**: the agent tests used the maintainer's own agent accounts; their cost is recorded in the evidence files.
* **Skills generated by the Creator** are `preview` until a person has reviewed the generated code and tests.
* **architecture-visualizer** limits: Graphviz layouts can be large; only layered, C4 context and C4 container views exist; analyzers cover package manifests and Python imports only.
